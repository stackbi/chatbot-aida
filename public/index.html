Intégration d'Aïda sur votre site

Ceci est une page de simulation qui montre le widget en action. Vous pouvez le configurer et l'entraîner en temps réel depuis le panneau d'administration.

💻 Script d'installation

Pour installer ce widget sur n'importe quel site web, il suffit de copier-coller cette ligne juste avant la balise de fermeture </body> :

<!-- Script Aïda -->
<script src="http://localhost:3000/widget.js" defer></script>
